# Additions to the IANA zone.tab for tools/gen_country_time_zones.py (review P1-15, 19.11.2026).
#
# zone.tab names one principal place per time zone. Taking the zone whose principal place is
# nearest to a photo picks the wrong zone in large parts of a few countries: Seattle and Portland
# lie nearer to Boise than to Los Angeles, Dallas and Nashville nearer to the small Indiana and
# Kentucky zones than to Chicago, Alice Springs nearer to Eucla than to Darwin, Quebec nearer
# to Moncton than to Toronto. The places below are more reference points for zones the country
# already has in zone.tab (the script refuses any other zone): big cities and much-visited
# places, most of them near the borders between the zones.
#
# CITY  <country> <zone> <latitude> <longitude> <name>   one more reference point
# MERGE <country> <territory>...                         the offline map counts these territories
#                                                        as part of the country (Natural Earth's
#                                                        France holds Réunion, Martinique, ...)
# DROP  <country> <zone>                                 leaves out the zone of an enclave whose
#                                                        clock has long been that of the country's
#                                                        main zone: its principal place would
#                                                        draw a large part of the country
# ALIAS <code> <zone>                                    a code Apple reports that zone.tab lacks
# AREA  <disputed area id> <country>                     a disputed area (DisputedAreas.swift)
#                                                        has no country code: the clock there is
#                                                        that of these zones. Areas not listed
#                                                        (Kashmir, Golan, Abkhazia) count as
#                                                        unknown (the home time zone).

MERGE FR GF GP MQ RE YT
MERGE NL BQ
MERGE AU CC CX
MERGE NZ TK

# since 1986. As reference places they would draw Baden-Württemberg, Bavaria and Andalusia.
# (Svalbard, which the offline map counts as part of Norway, keeps Oslo's clock: no merge.)

DROP ES Africa/Ceuta
